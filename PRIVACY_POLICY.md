# Политика конфиденциальности приложения MTZ Forge

Настоящая Политика конфиденциальности описывает порядок обработки данных в мобильном приложении **MTZ Forge** (пакет `com.bluequark.mtzforge`).

## 1. Сбор и хранение персональных данных
Приложение **не собирает, не хранит на внешних серверах и не передаёт третьим лицам** персональные данные пользователей. Все операции по обработке изображений (PSD, PSB, PNG) и сборке файлов тем (`.mtz`) выполняются исключительно локально на устройстве пользователя.

## 2. Запрашиваемые разрешения и доступ к данным на устройстве
Для выполнения заявленных функций приложение запрашивает доступ к следующим ресурсам устройства:
* **Список установленных приложений:** используется исключительно локально на устройстве для автоматического и ручного сопоставления создаваемых значков темы с именами пакетов (`packageName`) установленных программ и отображения их текущих иконок. Список приложений никуда не передаётся.
* **Файлы и память устройства:** используется только для чтения выбранных пользователем исходных файлов (PSD, PSB, PNG, MTZ) и сохранения сгенерированных файлов тем `.mtz` в память устройства.
* **Фоновая работа (по выбору пользователя):** используется исключительно при включении пользователем функции «Удерживать тему» для предотвращения автоматического сброса пользовательской темы оболочкой системы.

## 3. Сторонние сервисы и аналитика
В приложении отсутствуют рекламные SDK, скрытые трекеры и сторонние системы сбора аналитики.
