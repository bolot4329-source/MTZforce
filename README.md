# MTZ Forge

Утилита для Android, которую я собрал, чтобы делать и перекрашивать темы иконок `.mtz` под **Xiaomi HyperOS** прямо на телефоне — без компьютера, рута, Shizuku и сторонних костылей вроде Zyper.

Основная идея простая: закидываете свой `.psd` из Фотошопа, пачку `.png` или готовую тему-донор, настраиваете цвета под себя, при необходимости правите отдельные иконки встроенной кистью и на выходе получаете готовый `.mtz`, который сразу ставится через стандартное приложение «Темы».

---

## Что умеет

### Работа с PSD, PNG и готовыми темами
* **Прямой импорт PSD / PSB (RGB, 8 бит):** приложение само разбирает слои и группы («фон + логотип») на отдельные иконки. Если в исходнике значки разложены сеткой внутри папок — они автоматически распакуются.
* **Автопривязка к пакетам:** если слой назван по имени пакета (`com.android.chrome`), иконка привяжется со 100% точностью. Если слой называется просто `Telegram` или `blue_youtube` — приложение само найдёт подходящую программу среди установленных на телефоне (привязку всегда можно поменять вручную).
* **Пакетная загрузка PNG:** можно закинуть свои PNG-иконки пачкой или заменить любую конкретную иконку в проекте.
* **Режим темы-основы:** можно подгрузить любой готовый `.mtz` как базу — из него сохранятся обои, шрифты и все остальные ресурсы, а ваши новые иконки аккуратно лягут поверх.

### Перекраска и встроенный редактор
* **Умная работа с цветом:** перекрашивайте фон и логотип у одной иконки или сразу у всего пака залпом (по HEX-коду, ползункам или пресетам цветов в стиле iOS). Алгоритм сохраняет сглаживание, поэтому края не идут «лесенкой».
* **Глубокая палитра:** приложение находит все цвета внутри каждого значка (фон, глиф, обводку, дополнительные оттенки) — заменить можно любой из них. Есть общая палитра темы и готовые цветовые пары «основной + акцент» с автоподбором светлого оттенка.
* **Мини-редактор («Дорисовать»):** если где-то вылез косяк, не нужно возвращаться в Photoshop — прямо в приложении есть кисть, ластик, пипетка, заливка со сглаживанием краёв и история отмены/повтора.

### Глубокая кастомизация HyperOS (системные иконки и меню «Поделиться»)
* **Иконки внутри системных приложений:** можно достать, перекрасить или заменить на свой PNG внутренние значки Настроек, плиток шторки (Пункта управления), Звонилки, Камеры и других системных компонентов HyperOS. Ресурсы сохраняются строго в оригинальном разрешении с автоматической копией под тёмную тему.
* **Иконки любых установленных программ:** в разделе системных иконок можно вытащить текущий значок вообще любого приложения на устройстве (даже сервисного, у которого нет ярлыка на рабочем столе), перекрасить его и упаковать в тему.
* **Меню «Отправить / Поделиться»:** отдельная вкладка для кастомизации значков действий в системном меню шаринга (по правилам HyperOS вида `пакет#экран`, например `org.telegram.messenger#org.telegram.ui.LaunchActivity`).

## Как пользоваться

1. Нажмите **Открыть PSD** (либо выберите **Тема-основа** для готового `.mtz` или загрузите **PNG**).
2. Значки с красной подписью — это слои, которые ещё не нашли своё приложение. Нажмите на такой значок → **Приложение** и укажите нужную программу.
3. Используйте **Фон всем / Логотип всем** для быстрой массовой перекраски, или тапните по конкретной иконке для точечной настройки и подрисовки.
4. Нажмите **Собрать MTZ**, задайте имя темы и разрешение иконок (**192**, **432** или **512 px**).
5. Чтобы применить тему сразу: нажмите **Собрать и применить** — файл сохранится в `Загрузки/MTZ Forge` и откроется в системном приложении «Темы» (либо импортируйте его вручную: *Темы → Профиль → Мои темы → Импорт*).

> **Чтобы тема не слетала:** в меню приложения есть раздел **«Применение темы и проверка»**. Там можно включить фоновую службу **«Удерживать тему»**, которая не даёт HyperOS откатывать кастомную тему на стандартную, настроить автозапуск и батарею, а также в один клик убрать стандартную цветную подложку иконок HyperOS.

## Полезные советы и ограничения системы

* **Как сохранять PSD в Photoshop:** обязательно включайте галочку **«Максимальная совместимость» (Maximize Compatibility)** при сохранении файла — тогда значки вырезаются один в один как в Фотошопе, со всеми стилями и эффектами. Холст лучше оставлять прозрачным (но если в самом низу лежит сплошной фоновый слой на весь документ, приложение само поймёт это и пропустит его).
* **Где запускать:** собирать тему лучше прямо на том смартфоне Xiaomi, где вы планируете её использовать — список пакетов, системных ресурсов и пунктов меню «Поделиться» считывается напрямую с текущего устройства.
* **Нюансы системных иконок:**
  * Подмена внутренних ресурсов работает для системных приложений HyperOS (сторонние приложения вроде Telegram или банковских клиентов темы не затрагивают).
  * Переключатели с состояниями, анимации и индикаторы уровня по умолчанию скрыты фильтром «Только иконки», чтобы случайная замена на статичный PNG не сломала их логику.
  * Если системное приложение принудительно красит свои иконки в акцентный цвет системы, заменится только форма значка. А после применения темы лучше перезапустить Настройки/шторку или перезагрузить телефон.

## Сборка APK из исходников

Проект написан на **Kotlin (Jetpack Compose)** и собирается стандартным Gradle (пакет `com.bluequark.mtzforge`).

* **Через GitHub Actions (без Android Studio):** в репозитории настроен workflow `.github/workflows/build.yml`. При пуше или ручном запуске во вкладке **Actions → Build APK** собирается готовый APK, который можно забрать внизу страницы сборки в блоке **Artifacts** (`MtzForge-apk`).
* **Локально:** откройте папку проекта в Android Studio и запустите сборку **Build → Generate Signed App Bundle / APK**, либо выполните в терминале `gradle assembleRelease` (нужен установленный Gradle 8.x и Android SDK).

### Подпись APK

Ключ подписи **не хранится в репозитории**. Сборка работает в двух режимах:

* **Без настройки:** APK подписывается стандартным debug-ключом — можно сразу устанавливать на своё устройство, но обновления будут несовместимы с версиями, подписанными другим ключом.
* **С релизным ключом (рекомендуется):** создайте keystore командой

  ```
  keytool -genkeypair -v -keystore forge.keystore -alias forge -keyalg RSA -keysize 4096 -validity 10950
  ```

  и задайте параметры подписи одним из способов:

  * локально — в `~/.gradle/gradle.properties` (НЕ в папке проекта):
    ```
    FORGE_KEYSTORE_FILE=/полный/путь/к/forge.keystore
    FORGE_STORE_PASSWORD=пароль_keystore
    FORGE_KEY_ALIAS=forge
    FORGE_KEY_PASSWORD=пароль_ключа
    ```
  * для GitHub Actions — в **Settings → Secrets and variables → Actions** добавьте секреты `FORGE_KEYSTORE_BASE64` (результат `base64 -w0 forge.keystore`), `FORGE_STORE_PASSWORD`, `FORGE_KEY_ALIAS`, `FORGE_KEY_PASSWORD`.

Файлы `*.keystore` и `*.jks` внесены в `.gitignore` — случайно закоммитить ключ не получится.
