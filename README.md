# MTZ Forge

Приложение для Android, которое собирает тему значков `.mtz` для **Xiaomi HyperOS** прямо на телефоне — без компьютера, Root и Shizuku. Открываете свой `.psd` из Photoshop, пачку `.png` или готовую тему-донора, настраиваете цвета — и на выходе готовый `.mtz`, который ставится через стандартное приложение «Темы».

## Возможности

- **PSD → значки**
  - Прямой импорт PSD/PSB (RGB, 8 бит): слои и группы сами становятся значками, сетки внутри папок распаковываются.
  - Автопривязка к приложениям по имени слоя: `com.android.chrome` — со 100% точностью, `Telegram` или `blue_youtube` — подбор среди установленных (всегда можно поменять вручную).
  - Три режима чтения: «Авто», «Как в Photoshop» (точная картинка со всеми эффектами), «По слоям».
- **PNG и тема-основа**
  - Пакетное добавление своих PNG-значков, замена любого значка по одному.
  - Готовая тема `.mtz` как основа: обои, шрифты и остальные ресурсы берутся из неё, ваши значки ложатся поверх.
- **Перекраска и встроенный редактор**
  - Фон и логотип — одному значку или всем залпом (HEX, ползунки, пресеты). Алгоритм сохраняет сглаживание, края не идут «лесенкой».
  - Глубокая палитра: находятся все цвета внутри значка (фон, глиф, обводка, дополнительные) — заменить можно любой. Общая палитра темы и готовые пары «основной + акцент» с автоподбором светлого оттенка.
  - «Дорисовать»: кисть, ластик, пипетка, заливка со сглаживанием и история отмены/повтора — без возврата в Photoshop.
- **Глубокая кастомизация HyperOS**
  - Значки внутри системных приложений: пункты Настроек, плитки Пункта управления, Звонилка, Камера и другие — замена своим PNG или перекраска, строго в исходном разрешении, с автоматической копией для тёмной темы.
  - Значок любого установленного приложения (даже сервисного, без ярлыка) можно перекрасить и упаковать в тему.
  - Отдельная вкладка для значков меню «Поделиться» (правило HyperOS `пакет#экран`, например `org.telegram.messenger#org.telegram.ui.LaunchActivity`).
- **Применение и удержание темы**
  - «Собрать и применить»: тема сохраняется в `Загрузки/MTZ Forge` и открывается в приложении «Темы».
  - Фоновая служба «Удерживать тему» не даёт HyperOS откатить кастомную тему на стандартную; проверка значков на телефоне и уборка цветной подложки значков в один клик.

## Установка

1. Скачайте `MTZ-Forge-<версия>.apk` в разделе **[Releases](../../releases/latest)** и установите.
2. Собирайте тему на том смартфоне Xiaomi, где планируете её использовать: список пакетов, системных ресурсов и пунктов меню «Поделиться» считывается напрямую с устройства.
3. Разбор каждой функции — в [руководстве пользователя](docs/TUTORIAL.md).

## Безопасность

- Приложение работает полностью на устройстве: ничего никуда не отправляет, интернет не нужен.
- Root и Shizuku не требуются: тема применяется штатно, через системное приложение «Темы».
- Ключ подписи релизов хранится только в секретах репозитория; в коде и в дереве ветки `main` ключей нет.
- Пользуйтесь на свой страх и риск: замену ресурсов системных приложений HyperOS делайте осознанно — оригинал возвращается кнопкой «Вернуть оригинал» у каждого значка.

## Сборка из исходников

APK собирается в GitHub Actions (`.github/workflows/build.yml`). Используются Gradle 8.11.1, AGP 8.7.3 и Kotlin 2.0.21; версии зависимостей — в каталоге `gradle/libs.versions.toml`. Релизы подписываются ключом из секретов репозитория (`FORGE_KEYSTORE_BASE64`, `FORGE_STORE_PASSWORD`, `FORGE_KEY_ALIAS`, `FORGE_KEY_PASSWORD`). Без секретов (например, в форке) release-APK подписывается отладочным ключом и **не совместим** с официальными релизами.

- **Через GitHub Actions (без Android Studio):** вкладка **Actions → Build MTZ Forge APK → Run workflow**, готовый APK — внизу страницы сборки в блоке **Artifacts**. Запуск с `publish = true` (или пуш тега `v*`) публикует GitHub Release с APK.
- **Локально:** откройте папку проекта в Android Studio и запустите **Build → Generate Signed App Bundle / APK**, либо выполните в терминале `gradle assembleRelease` (нужны Gradle 8.x и Android SDK).

Технические подробности для контрибьюторов — в `CLAUDE.md`, журнал ревизий — в `docs/gemini-log.md`.
