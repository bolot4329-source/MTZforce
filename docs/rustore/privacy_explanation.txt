Приложение MTZ Forge — конструктор тем значков (.mtz) для HyperOS (Xiaomi). Основная функция приложения — настройка и замена значков установленных приложений и системных компонентов устройства (перекраска, замена изображений) с последующей сборкой файла темы для штатного приложения «Темы» HyperOS.

Разрешение android.permission.QUERY_ALL_PACKAGES критично для основной функциональности:
1. Экран «Системные» (SysViewModel) получает полный перечень установленных пакетов через PackageManager.getInstalledApplications, чтобы пользователь мог выбрать для оформления не только обычные приложения с ярлыком, но и системные компоненты HyperOS и пакеты без ярлыка на рабочем столе (например, android, com.android.systemui, miui.systemui.plugin, com.android.intentresolver и др.).
2. Приложение читает текущие значки и ресурсы выбранных пакетов через getApplicationInfo и getResourcesForApplication для предпросмотра и формирования замены в теме.
3. При разборе имён значков проверяется наличие соответствующих пакетов на устройстве (getPackageInfo), чтобы корректно сопоставлять ресурсы установленным пакетам.

Альтернатива через блок <queries> недостаточна: стандартные intent-фильтры (MAIN/LAUNCHER и SEND) уже используются для обычных ярлыков и меню «Поделиться», но не дают видимости системных пакетов без ярлыка и произвольных приложений без соответствующих обработчиков. Заранее перечислить все пакеты в <queries> невозможно, поскольку набор приложений зависит от конкретного устройства и выбора пользователя.

Как проверить работу разрешения: откройте в приложении экран «Системные» — отобразится список установленных пакетов устройства; выберите любой системный или скрытый пакет, чтобы просмотреть и заменить его значки для сборки темы .mtz.

Обработка данных и безопасность:
- Сведения об установленных пакетах используются строго локально на устройстве в оперативной памяти для отображения списка и сборки темы.
- Полный список приложений не сохраняется и не экспортируется; в создаваемый файл .mtz попадают только ресурсы тех пакетов, которые пользователь выбрал вручную.
- В манифесте и собранном APK отсутствует разрешение android.permission.INTERNET: приложение полностью автономно, не выполняет сетевых запросов, не передаёт данные третьим лицам и не использует их для рекламы или аналитики.

Прочие чувствительные разрешения (профилактическое пояснение):
- FOREGROUND_SERVICE и FOREGROUND_SERVICE_SPECIAL_USE: фоновая служба удержания темы не даёт HyperOS откатить применённую пользователем тему — перехватывает системные оповещения (CHECK_TIME_UP, CHECK_THEME_UPDATE), по которым приложение «Темы» откатывает сторонние темы. Служба работает только при включённом пользователем переключателе «Удержание темы» и показывает постоянное уведомление.
- RECEIVE_BOOT_COMPLETED: перезапуск службы удержания темы после перезагрузки устройства, только если пользователь включил удержание.
- REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: исключение из оптимизации батареи через системный диалог по нажатию пользователя, чтобы HyperOS не выгружала службу удержания темы.
