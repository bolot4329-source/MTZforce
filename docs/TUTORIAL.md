# Руководство пользователя MTZ Forge

MTZ Forge собирает тему значков `.mtz` для Xiaomi HyperOS прямо на телефоне. Это руководство разбирает каждую функцию по шагам.

## Быстрый старт

1. Нажмите **Открыть PSD** (или **Открыть тему MTZ (основа)** для готового `.mtz`, либо **Добавить PNG-значки**).
2. Значки с красной подписью ещё не нашли своё приложение: нажмите на такой значок → **Приложение** и укажите нужную программу.
3. Используйте **Фон всем / Логотип всем** для массовой перекраски или тапните по конкретному значку для точечной настройки.
4. Нажмите **Собрать MTZ**, задайте название темы, автора и размер значков (**192**, **432** или **512 px**).
5. **Собрать и применить** — файл сохранится в `Загрузки/MTZ Forge` и откроется в системном приложении «Темы». Либо **Только сохранить** и импортируйте вручную: *Темы → Профиль → Мои темы → Импорт*.

## Подготовка PSD в Photoshop

- Сохраняйте файл с галочкой **«Максимальная совместимость» (Maximize Compatibility)** — тогда режим «Как в Photoshop» вырезает значки один в один, со всеми стилями и эффектами.
- Называйте слои именами пакетов (`com.android.chrome`) или названиями приложений — привязка произойдёт сама.
- Холст лучше оставлять прозрачным. Если в самом низу лежит сплошной фоновый слой на весь документ, приложение само поймёт это и пропустит его.
- Поддерживаются PSD и PSB, цвет RGB, 8 бит на канал.

### Режимы чтения PSD

- **Авто** — приложение само выбирает подходящий способ.
- **Как в Photoshop** — точная итоговая картинка слоя со всеми эффектами (нужна «Максимальная совместимость»).
- **По слоям** — если на холсте есть общий фон или значки наложены друг на друга.

## Привязка значков к приложениям

- Слой с именем пакета (`com.android.chrome`) привязывается со 100% точностью.
- Слой с человеческим названием (`Telegram`, `blue_youtube`) — приложение ищет подходящую программу среди установленных.
- Значок без привязки подписан красным и при сборке пропускается. Нажмите на него → **Приложение** → выберите из списка.

## Перекраска

- **Пары цветов** — готовые сочетания «основной + акцент»; свой основной цвет задаётся через «Основной цвет (дополнительный подберётся светлее)».
- **Фон всем / Логотип всем** — залповая перекраска всего пака.
- **Палитра темы** (полоса над сеткой значков) — замена конкретного цвета темы во всех значках, где он встречается.
- Тап по значку → ряд цветовых точек: фон, логотип, дополнительные цвета — заменяется любой. Алгоритм сохраняет сглаживание краёв.
- **Сбросить цвета** возвращает исходную палитру значка.

## Мини-редактор «Дорисовать»

В карточке значка → **Дорисовать: заливка и кисть**. Доступны кисть, ластик, пипетка, заливка со сглаживанием краёв, история отмены/повтора. Удобно, чтобы быстро поправить косяк, не возвращаясь в Photoshop.

## Значки внутри приложений

Раздел **«Значки внутри приложений»** (меню ⋮ или кнопка на стартовом экране):

- **«Значок»** у строки приложения — значок самого приложения (рабочий стол, Настройки, недавние).
- Нажатие на строку — картинки **внутри** приложения: иконки пунктов Настроек, плитки Пункта управления и т.д. У каждой картинки: **Заменить PNG**, **Цвет**, **Вернуть оригинал**.
- **Цвет всем иконкам** красит все значки выбранного приложения разом; **Сбросить приложение** откатывает все его правки.
- Фильтр **«Только иконки»** скрывает переключатели с состояниями, анимации и индикаторы уровня — их случайная замена на статичный PNG сломала бы логику.
- Ресурсы сохраняются строго в исходном разрешении, с автоматической копией `night-xxhdpi` для тёмной темы.

Ограничения: подмена внутренних ресурсов работает для системных приложений HyperOS; сторонние программы (Telegram, банки) темы не затрагивают. Если системное приложение само красит иконки в акцентный цвет, заменится только форма. После применения темы перезапустите Настройки/шторку или перезагрузите телефон.

## Меню «Поделиться»

Вкладка **«Меню „Поделиться“»** в том же разделе — значки действий системного меню шаринга. Подписи под пунктами:

- **общий значок** — меняется вместе со значком приложения;
- **свой значок** — подменяется картинка внутри приложения (правило HyperOS `пакет#экран`);
- **не меняется** — векторный значок, тема HyperOS его не трогает.

## Применение темы и проверка

Меню ⋮ → **«Применение темы и проверка»**:

- **Удерживать тему** — фоновая служба не даёт HyperOS откатить кастомную тему на стандартную (как Zyper, но встроено). Чтобы службу не выгружали, разрешите автозапуск и «нет ограничений» для батареи кнопками **Батарея** и **Автозапуск**.
- **Проверить значки на телефоне** — сверка темы с реально применёнными значками.
- **Убрать цветную подложку значков** — отключает стандартную цветную подложку значков HyperOS.

## Советы

- Собирайте тему на том устройстве, где будете её использовать.
- Для полной темы (обои, шрифты) всегда берите рабочий `.mtz` как основу — без основы в теме будут только значки.
- 432 px — оптимальный размер значков для большинства устройств; 512 px — для планшетов и высокой плотности экрана.
